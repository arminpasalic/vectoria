                            About Vectoria
                            

                                
A browser-native semantic search and document-answer system. Processing stays local by default. In AI client mode via MCP, only retrieved excerpts or cluster examples are shared with your selected provider.

                                

                                    
WebLLM — LLM inference

                                    
Transformers.js — Embeddings

                                    
ONNX Runtime — ML runtime

                                    
WebGPU — GPU acceleration

                                    
UMAP WASM — Dimensionality reduction

                                    
HDBSCAN — Clustering

                                    
BM25 — Keyword search

                                    
IndexedDB — Local storage

                                

                                
No telemetry · No tracking · Models cached locally

                    Set up private, browser-native AI for semantic search, clustering, and document-grounded answers.
                

                

                    
 Processing stays on this device. Models are cached in browser storage.

                    
 Chrome or Edge with WebGPU; 16 GB RAM recommended.

                

                
Two models are downloaded once and remain out of memory until their work needs them.

                

                    

                        
Embeddings model

                        
Loads when document processing or semantic retrieval begins.

                        
Converts text into numerical vectors so similar content can be grouped and searched by meaning.

                        
Model: intfloat/multilingual-e5-small

                    

                    

                        
Language model

                        
Stays unloaded during document processing and loads for your first document question.

                        
Generates natural language answers to your questions using relevant documents as context.
